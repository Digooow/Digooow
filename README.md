## 📐 Engenharia de Software Aplicada

Em vez de projetos apenas demonstrativos, estruturo meus repositórios aplicando práticas reais de produção:

| Pilar | Como aplico nos meus repositórios |
| :--- | :--- |
| 🏛️ **Arquitetura & Domínio** | **Clean Architecture** (`Domain`, `Application`, `Infrastructure`, `Presentation`), **DDD Tático** (*Value Objects*, entidades ricas, *Unit of Work*) e separação de responsabilidades em APIs REST (.NET e NestJS) e Desktop (MVVM/WPF). |
| 🔒 **Consistência & Concorrência** | Transações ACID no PostgreSQL, **Pessimistic Locking**, **Ledger append-only**, chaves de **Idempotência**, padrão **Inbox/Outbox** e processamento assíncrono com workers. |
| 🤖 **AI-First Engineering** | Uso avançado de **Engenharia de Prompts**, **Agentes de IA** e **GitHub Copilot** para design arquitetural, geração de baterias de testes (unitários, integração e concorrência), refatoração e documentação técnica. |
| ⚙️ **DevOps, CI/CD & Dados** | Ambientes isolados com **Docker Compose**, pipelines de build/teste e automação deste próprio perfil via **GitHub Actions**, além de pipelines de dados transacionais (ETL) em Python e SQL. |
| 🛡️ **Redes & Cibersegurança** | Autenticação **JWT**, hash seguro de credenciais, validação de contratos de entrada, controle de acesso por perfil (RBAC) e fundamentos de segurança de redes e containers. |
